# NMDC MMO 鯨豚觀察作業系統

依「台灣鯨豚觀察員制度作業指引（第四版）」製作的施工批次鯨豚觀察紀錄系統。

- 前端：`index.html`（GitHub Pages）
- 後端：`mmo-gas/Code.js`（Google Apps Script，clasp push + `clasp deploy -i <prod id>`）
- 資料：Drive 資料夾「11 - 鯨豚觀察儀錶板」內的試算表「MMO 鯨豚觀察總表」；
  上傳檔案放在 `<日期>_批次<N>_<施工船>/`：`軌跡/`（結束實際觀測時自動存圖）、`<MMO 船>/紙本紀錄/`、`<MMO 船>/照片/<MM-DD_00-12>/`（照片每 12 小時時段一組，範圍＝預觀測開始到實際觀測結束）

## 流程
批次（1 施工船 + 多艘 MMO 船）→ 每艘 MMO 船：預觀測開始/結束（≥30 分）→ 實際觀測開始 →
目擊／暫停施工／回復施工（可多次）→ 實際觀測結束 → 上傳各項自檢表、紀錄表與監測照片 → 結案。

重新預觀測：暫停施工超過 60 分（後台可調），或鯨豚進入 750 m 警戒區，須於鯨豚離開後重做 30 分預觀測才可回復施工；
紀錄在該筆暫停施工（Pauses.pre_start / pre_end）。

船距：以兩船最新 AIS 計算施工船 ↔ MMO 船距離，750 m ± 容許值（後台可調，預設 150 m）內視為「在附近」；
一個批次＝預觀測開始到施工船宣布停工（實際觀測結束），中間暫停與重新預觀測都算同一筆；這段期間 MMO 船與施工船自動記錄軌跡，施工船等同批次所有進行中的 MMO 船結束才停。

任一船定位超過 30 分鐘視為過舊，不做判定。進行中的批次超出範圍時跳出警告視窗，仍在範圍外每 30 分鐘再提醒。

## 離岸環保統計（v1.6，只有管理員可看可填）
- 船舶主檔：類別多「支援船」；加起租日／退租日、燃料種類、「需填每日環保資料」。起租日到退租日（或昨天）之間每天都是應填日
- 每日填報（EnvDaily）：選日期一次填所有船：用油／加油／油存量 ROB（L）、用水／加水／造水（m³）、在船人數；ROB 與前日不符會提醒
- 廢棄物交運（EnvWaste）：每次交運一筆，各類別 kg，附聯單（Drive `環保/<船名>/廢棄物聯單/`）
- 環境事件（EnvIncidents）：類型、嚴重度（虛驚／輕微／重大）、處置與結案；「連續零事件天數」不含虛驚
- CO₂＝用油 L × 密度 ÷ 1000 × 排放係數（後台 › 規則與清單 › 環保統計，可調）
- 儀表板 KPI 列、環保統計頁總覽與月報 CSV；環保資料不放進共用快取，只在管理員的 data.load 回傳

## 首次安裝
1. 在 GAS 編輯器執行一次 `setup()`（授權 Drive／試算表，建立總表）
2. 開網頁 → 建立第一個管理員 → 後台新增船舶、觀察員、帳號
